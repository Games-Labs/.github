## Sobre

A Games Labs é um espaço pessoal para reunir trabalhos acadêmicos, estudos de Ciência da Computação e experimentos de desenvolvimento de software. Os projetos são publicados aqui com uma apresentação organizada, para servir de portfólio e de registro do que está sendo aprendido.

Não é uma empresa: é um laboratório em evolução, e os repositórios refletem esse processo.

## Áreas de interesse

- **Projetos acadêmicos**: trabalhos desenvolvidos como parte dos estudos.
- **Desenvolvimento de software**: aplicações, jogos e ferramentas.
- **Ciência da Computação**: algoritmos, estruturas de dados e fundamentos da programação.
- **Experimentações tecnológicas**: provas de conceito e testes com novas tecnologias.
- **Projetos pessoais**: ideias que merecem um repositório bem apresentado.
